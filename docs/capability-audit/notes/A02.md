## Capabilities

### CAP-A02-001: CFG Builder — ARC EM/HS
- **name:** `build_cfg` in `cfg_arc.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_arc.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** Constructs a basic-block CFG from a decoded ARC EM/HS instruction stream. Handles ARC delay-slot instructions: instructions with `.d` suffix have a delay slot; the delay-slot instruction is attached to the terminating block and successor VAs are computed after the delay slot, not after the branch opcode.
- **inputs:** `Sequence[Insn]` from `insn_arc.py`; optional `entry` VA override
- **outputs:** `CFG` dataclass with `blocks: Dict[int, Block]`, `entry: int`; `Block` has `insns`, `succs: List[int]`
- **scope:** ARC EM/HS; handles `.d` delay-slot suffixed branches; `bbit0`/`bbit1` bit-test branches
- **status:** implemented
- **evidence:** Used by analysis_arc.py
- **docs:** `control-flow-graph-construction.md` lists `cfg_arc.py` under ISA-specific builders; entry matches
- **limitations:** No analysis_sh2a.py counterpart—SH-2A has a CFG but no standalone analysis engine file in this unit
- **dependencies:** `insn_arc.py`, `isa_arc.py`

### CAP-A02-002: CFG Builder — ARM32/Thumb
- **name:** `build_cfg` in `cfg_arm32.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_arm32.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** Constructs a basic-block CFG from ARM32/Thumb instruction stream. Identifies return instructions via pattern matching: `bx lr`, `pop {pc}` / `pop {...,pc}`, `ldm*` with PC in register list, `mov pc,lr`. No delay slots.
- **inputs:** `Sequence[Insn]` from `insn_arm32.py`; optional entry VA
- **outputs:** `CFG` dataclass
- **scope:** ARM32 and Thumb modes; IT-block handling via Thumb conditional execution codes
- **status:** implemented
- **docs:** `control-flow-graph-construction.md` lists under ISA-specific builders; accurate
- **dependencies:** `insn_arm32.py`

### CAP-A02-003: CFG Builder — AArch64
- **name:** `build_cfg` in `cfg_arm64.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_arm64.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** Constructs a basic-block CFG for AArch64. Delegates branch classification to an `ISA` model: reads `ISA.ret_mnems`, `ISA.call_mnems`, `ISA.indirect_jump_mnems`, `ISA.uncond_branch_mnems`, `ISA.cond_branch_mnems`, `ISA.reg_branch_mnems`. Handles `cbz`/`cbnz`/`tbz`/`tbnz` conditional branches.
- **scope:** AArch64 (LP64 ABI)
- **status:** implemented
- **docs:** `control-flow-graph-construction.md` accurate
- **dependencies:** `insn_arm64.py`, `isa_arm64.py` (ISA model)

### CAP-A02-004: CFG Builder — LoongArch64
- **name:** `build_cfg` in `cfg_loongarch64.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_loongarch64.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** CFG for LoongArch64 instruction stream. `jirl` instruction is polymorphic: `jirl $zero,*,0` = return, `jirl $ra,$ra,0` = indirect call, other = indirect branch. `break`/`dbcl` instructions treated as traps (no successors). `ertn` (exception return) also treated as no-successor terminator.
- **scope:** LoongArch64 lp64 ABI; all branch forms including extended-range `beqz`/`bnez`/`bl`
- **status:** implemented
- **docs:** `loongarch64.md` covers the full stack; CFG section accurate
- **dependencies:** `insn_loongarch64.py`

### CAP-A02-005: CFG Builder — MIPS32/64
- **name:** `build_cfg` in `cfg_mips.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_mips.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** CFG for MIPS32/64. Delay slots are mandatory: every branch/jump carries a delay-slot instruction whose effects are committed before the branch takes effect. Compact branches (`COMPACT_BEQ`, `COMPACT_BNE`, etc.) have no delay slot and are handled separately. `jr $ra` = return; `jr $t9` = indirect jump (common for PLT).
- **scope:** MIPS32 and MIPS64 (O32/N32/N64 ABIs); nanoMIPS handled in separate module
- **status:** implemented
- **docs:** `control-flow-graph-construction.md` accurate
- **dependencies:** `insn_mips.py`, `isa_mips.py`

### CAP-A02-006: CFG Builder — PPC32/64
- **name:** `build_cfg` in `cfg_ppc.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_ppc.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** CFG for PowerPC 32/64. `BCC_CTR` (branch-conditional-to-CTR, e.g. `bdnz`, `bdzf`) has NO fall-through — always terminates the block. `bcclr` (conditional return to LR) is treated conservatively: adds fall-through successor (may or may not branch). `blr` = unconditional return.
- **scope:** PPC32 and PPC64; `bc`/`bcl` conditional link instructions
- **status:** implemented
- **docs:** `control-flow-graph-construction.md` accurate
- **dependencies:** `insn_ppc.py`, `isa_ppc.py`

### CAP-A02-007: CFG Builder — RISC-V
- **name:** `build_cfg` in `cfg_riscv.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_riscv.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], isa: IsaModel, entry: Optional[int] = None) → CFG`
- **what it does:** CFG for RISC-V 32/64. Takes an explicit `IsaModel` parameter (unlike all other `cfg_*.py` builders). `jal rd==zero` = unconditional jump; `jal rd!=zero` = call (adds fall-through). RVC (16-bit compressed) branches handled through the `IsaModel` abstraction.
- **scope:** RV32 and RV64; compressed (C) extension; ISA model passed at call time
- **status:** implemented
- **limitations:** Unique in requiring an explicit `IsaModel` arg — callers must call `isa_for(width)` first
- **docs:** `control-flow-graph-construction.md` accurate
- **dependencies:** `insn_riscv.py`, `isa_riscv.py`, `IsaModel` from `isa_riscv.py`

### CAP-A02-008: CFG Builder — SH-2A
- **name:** `build_cfg` in `cfg_sh2a.py`
- **category:** CFG Construction
- **paths:** `ablation/analyzers/cfg_sh2a.py`
- **entry point:** `build_cfg(insns: Sequence[Insn], entry: Optional[int] = None) → CFG`
- **what it does:** CFG for Renesas SH-2A (ECU firmware). Handles SH-2A delay-slot branches: the instruction after a branch fires before the branch takes effect. Unique: this `CFG` adds `.flow` property (list of `(src, dst)` edge tuples) and `.flow_r()` method for reverse edges — required by `dataflow_engine.DomTree` and `LoopInfo`. No other CFG module implements this interface.
- **scope:** Renesas SH-2A; Bosch EDC, Denso, Siemens ECU firmware
- **status:** implemented
- **limitations:** No `analysis_sh2a.py` exists — there is a `cfg_sh2a.py` and `cfg-sh2a.md` but no corresponding fixpoint analysis engine
- **docs:** `cfg-sh2a.md` accurate; correctly notes `.flow`/`.flow_r()` for `dataflow_engine` compatibility
- **dependencies:** `insn_sh2a.py` (implied), `ecu_sh2a_decoder.py`

### CAP-A02-010: CFG Builder — x86/x86-64

### CAP-A02-011: Fixpoint Analysis Engine — ARC EM/HS
- **name:** `analyze_cfg` in `analysis_arc.py`
- **category:** CFG Dataflow Analysis
- **paths:** `ablation/analyzers/analysis_arc.py`
- **entry point:** `analyze_cfg(insns, mode=Mode.EM, initial=None, policy=None, entry=None, max_iterations=10_000) → CFGResult`
- **what it does:** Path-insensitive, flow-sensitive BFS worklist fixpoint analysis over an ARC CFG. Calls `_loop_heads()` (DFS back-edge detection) then iterates: for each block, runs `TaintTracker(mode, policy=policy)`, joins predecessor exit states at block entry, widens at loop heads after ≥2 visits. De-duplicates findings by `(address, kind, labels)`.
- **inputs:** ARC instruction sequence + initial taint state; policy overrides sink/source config
- **outputs:** `CFGResult(cfg, findings, entry_states, exit_states, iterations, unknown, unreachable)`
- **scope:** ARC EM and HS modes
- **status:** implemented
- **dependencies:** `cfg_arc.py`, `taint_tracker_arc_labeled.py`, `isa_arc.py`

## CFGResult Schema (all engines share this)
```
CFGResult:
  cfg:           CFG              — the built basic-block graph
  findings:      List[Finding]    — de-duplicated, sorted by address
  entry_states:  Dict[int, State] — taint state at entry to each block
  exit_states:   Dict[int, State] — taint state at exit from each block
  iterations:    int              — total worklist iterations (convergence cost)
  unknown:       Set[str]         — register/memory operands the engine couldn't classify
  unreachable:   List[int]        — block start VAs never reached by the worklist
```

## Cross-cutting observations

**Architecture of the fixpoint engine:** Every `analysis_*.py` is structurally identical code: `_loop_heads()` DFS + BFS worklist with `join()`+`widen` at loop heads. The only variation is: (1) which taint class is imported, (2) whether a `mode`/`width`/`variant` parameter is threaded through, (3) whether `policy` is available.

**Naming inconsistency:** Some engines use `TaintTracker`, others use `TaintEngine`:
  - `TaintTracker`: ARC, ARM32, MIPS, PPC, x86
  - `TaintEngine`: AArch64, LoongArch64, RISC-V, V850

**No analysis_sh2a.py exists.** There is a `cfg_sh2a.py` with the `.flow`/`.flow_r()` interface for `dataflow_engine`, but no corresponding `analysis_sh2a.py` fixpoint engine. SH-2A dataflow uses `dataflow_engine.py` directly (a different, separate system).

**nanoMIPS absent here.** The work unit list includes `cfg_mips.py` but nanoMIPS has its own stack. Tracked separately in A05.
