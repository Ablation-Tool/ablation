### 1. FormatStringScanner

- **name**: `FormatStringScanner`
- **category**: Vulnerability Detection / Format String
- **paths**: `ablation/analyzers/format_string_scanner.py` (416 lines)
- **entry point**: `FormatStringScanner.from_context(ctx)` or `from_path(path)`; `scanner.scan()` → `List[FmtStringFinding]`; `scanner.report(findings)` → str; CLI: `python3 -m ablation.analyzers.format_string_scanner <binary>`
- **what it does**: Detects non-constant format string arguments at printf-family and syslog/err/warn call sites in x86-64 ELF binaries. Per call site, walks back ≤20 instructions to find the last write to the format register and classifies provenance as rodata (safe), arg_passthrough (HIGH), stack_load (MEDIUM), register (MEDIUM), or unknown (MEDIUM).
- **inputs / outputs**: x86-64 ELF binary. Output: `FmtStringFinding` dataclass with fields `func_va, call_va, callee, fmt_reg, provenance, severity, description`. Severities: HIGH (arg_passthrough), MEDIUM (stack_load/register/unknown), SAFE (rodata).

- **status**: implemented
- **evidence**: referenced in CLAUDE.md tool selection chain; no dedicated test file in this unit's assignment
- **docs**: check reference-modules/ for format_string_scanner.md
- **limitations**: x86-64 only; 20-instruction lookback window may miss indirect propagation; does not follow call chains interprocedurally

### 19. LA64MaxNotMinScanner
