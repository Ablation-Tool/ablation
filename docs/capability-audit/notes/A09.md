- **paths:** `ablation/analyzers/fortios_firmware_extractor.py:1-422`

- **what it does:** 4-step pipeline: (1) ZIP unwrap for v8.0.0+ OVF distributions (STORE compression), (2) first-gzip decompression, (3) 64-byte XOR key recovery via IC+frequency analysis using `XorSolver`, (4) partition scan against 16 known partition magic bytes; extracts all found partitions.

- **status:** implemented
- **evidence:** Confirmed production results listed in module docstring.
- **docs:** Likely in Fortinet workflow docs.
- **limitations:** Assumes NAND 0xFF-dominant plaintext by default; pass `plaintext_assumption=0x00` for x86 0x00-dominant. Caller must call `result.cleanup()` or pass `output_dir=`.
- **dependencies:** `XorSolver` (internal ablation module), stdlib zipfile/gzip.
