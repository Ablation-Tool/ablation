## Capability: CrossBinaryTaintTracker — cross-library interprocedural taint
- **name:** CrossBinaryTaintTracker, TaintChain, TaintHop
- **category:** Taint Analysis / Cross-binary
- **paths:** ablation/analyzers/cross_binary_taint.py
- **entry point:** `CrossBinaryTaintTracker(entry_binary, lib_graph, max_hops=6).run()` → list[TaintChain]
- **what it does:** Extends single-binary TaintTracker to follow tainted arguments across shared library boundaries. When a tainted arg is passed to a PLT stub, resolves the target in LibGraph, loads that binary's BinaryContext, and continues the BFS from the exported function. Produces full cross-binary chains like `libservice.so:recv_wrapper → libdata.so:parse_packet → libcmd.so:exec_command → system()`.
- **scope:** All ELF shared libraries; uses x86-64 TaintTracker internally
- **status:** implemented
- **deps:** TaintTrackerX86 (taint_tracker_x86.py), LibGraph, BinaryContext

## Capability: LibGraph — cross-binary import/export matrix
- **name:** LibGraph, LibCaller
- **category:** Taint Analysis / Cross-binary
- **paths:** ablation/analyzers/lib_graph.py
- **entry point:** `LibGraph.from_dir('/path/to/lib/')` or `LibGraph.from_paths([...])` → LibGraph
- **what it does:** Loads BinaryContext for every ELF in a firmware directory (cache hit ~110ms/binary), builds a unified index of exports, import relationships, and cross-binary callers. Methods: `callers_of(name)`, `defined_in(name)`, `imports_of(binary)`, `exports_of(binary)`, `summary()`. Used by CrossBinaryTaintTracker to resolve PLT targets.
- **scope:** ELF shared libraries (.so)
- **status:** implemented
- **deps:** BinaryContext

## Capability: PrivDropBeforeExec — privilege drop before exec detector
- **name:** PrivDropBeforeExecAnalyzer
- **category:** Vulnerability Scanning / Privilege Escalation
- **paths:** ablation/analyzers/priv_drop_before_exec.py
- **entry point:** `PrivDropBeforeExecAnalyzer.from_context(ctx).scan()` → findings list
- **what it does:** Detects the SAFE privilege-drop pattern in SETUID binaries: within a single function, detects getuid() → setuid/seteuid/setreuid(getuid result) → exec*(). ## Capability: SourceTaintTracker — inter-procedural source code taint tracing
- **name:** SourceTaintTracker, TaintPath
- **category:** Source Code Auditing / Taint Analysis
- **paths:** ablation/analyzers/source_taint_tracker.py
- **entry point:** `SourceTaintTracker(ctx).build().trace(sinks)` → list[TaintPath]
- **what it does:** Backward-slices from SinkScanner hits to HTTP route handlers. Walks the call graph backward until a route handler (Next.js `pages/api/` or `app/api/` exporter) is found. - **scope:** Next.js TypeScript/JavaScript (primary); Python FastAPI (partial)
- **status:** implemented
- **deps:** SourceContext, SourceSinkScanner

## Capability: SourceAuditCompressor — profile-based batch source audit
- **name:** SourceAuditCompressor
- **category:** Source Code Auditing / Efficiency
- **paths:** ablation/analyzers/source_audit_compressor.py
- **entry point:** `SourceAuditCompressor.from_context(ctx).compress()` → audit plan
- **what it does:** Assigns each source file a 5-bit security profile (0–31) encoding presence of: unsafe_render, href_binding, URL_assignment, user_data_render, shared_module. Files sharing a profile are batchable — one representative read covers all. Profile-0 files (~97% of a typical codebase) need only one representative read. Reduces a 2861-file TS codebase to ~71 files needing individual attention.
- **scope:** TypeScript/JavaScript repos
- **status:** implemented
- **deps:** SourceContext

## Capability: SourceArchRisk — "safe now, catastrophic later" architectural risk scanner
- **name:** SourceArchRiskScanner, RiskFinding
- **category:** Source Code Auditing / Architectural Risk
- **paths:** ablation/analyzers/source_arch_risk.py
- **entry point:** `SourceArchRiskScanner.from_context(ctx).scan()` → list[RiskFinding]
- **what it does:** Detects files that combine unsafe rendering primitives (`innerHTML`, `unsafeHTML`, `dangerouslySetInnerHTML`, `eval`) with extensible dispatch patterns (type-dispatch switch, string-based component selector, registry lookup, shared module). - **scope:** TypeScript/JavaScript
- **status:** implemented
- **deps:** SourceContext
