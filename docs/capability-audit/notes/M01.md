### CAP-01 — DockerEnumerator

- **name:** `DockerEnumerator` (class) + `enumerate_all()`, `report()`
- **category:** Container enumeration / escape-vector detection
- **paths:** `modules/docker_enum.py` lines 26–822
- **entry point:** `DockerEnumerator(); enum.enumerate_all(); enum.report()`
- **what it does:** Detects whether the caller is running inside a container; checks Docker socket accessibility; enumerates running containers, images, volumes, and networks via `docker` CLI subprocess; checks for privileged mode and dangerous capabilities; probes TCP 2375 (unauthenticated daemon API) and 2376 (TLS with no cert verification); inspects per-container flags (privileged, dangerous CapAdd, dangerous mounts, ports bound to 0.0.0.0, secret-like env vars); scans image history for risky Dockerfile patterns.
- **inputs / outputs:** No constructor parameters. `enumerate_all()` returns a dict with in_container, socket_access, privileged, containers, images, volumes, networks, capabilities, mounts, escape_vectors, and five findings lists. `report()` returns a formatted string. All finding dicts use `{severity, title, detail, ...}`.
- **scope:** Linux and macOS (conditional branching on `_IS_LINUX`/`_IS_MACOS`). Requires Docker CLI for socket-based checks. TCP probe targets `localhost:2375/2376` by default.
- **status:** implemented
- **evidence:** No unit test file found for this module in `tests/`.
- **docs:** `docs/reference-modules/docker-enum.md` and `docs/reference-modules/docker-inventory-and-posture.md`. The `docker-enum.md` doc matches the implementation closely, including the FORGE audit status.
- **limitations:** `check_socket_access()` calls `docker ps` subprocess — fails silently if Docker CLI not installed. `check_in_container()` uses a hostname-length heuristic (12-char hex) that could false-positive. TLS probe on 2376 does not verify the certificate.
- **dependencies:** `subprocess`, `json`, `os`, `socket`, `ssl`, `urllib.request` (all stdlib). Docker CLI for socket checks.
- **claims to verify:** Doc says `probe_docker_daemon_api()` always runs "no socket needed" — confirmed by code at lines 46–71.
