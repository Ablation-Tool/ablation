### CAP-A07-01 — SinkArgClassifier (x86-64 dispatch hub)

**File:** `sink_arg_classifier.py`  
**Class:** `SinkArgClassifier`  
**Gap IDs fixed:** None (hub for all arches; x86-64 native path)

**Verdict classes (5):**
- `RODATA_CONST` — arg is a .rodata address or literal immediate
- `SNPRINTF_RODATA` — stack buffer filled by snprintf with RODATA_CONST format string
- `ARG_PROPAGATED` — arg traces back to entry-point register (rdi/rsi/rdx/rcx/r8/r9)
- `UNKNOWN` — provenance not resolved within lookback window
- `UNICODE_WRAPPER` — VMware VDDK pattern: `Unicode_GetAllocBytes` PLT call before sink

**Architecture scope:** x86-64 native; dispatch hub for all other arches via `from_context(ctx)`.

**Constructors:**
- `SinkArgClassifier.from_context(ctx)` — arch-dispatches to per-arch subclass based on ELF machine type and endianness; REQUIRED for stripped binaries
- `SinkArgClassifier.from_path(path)` — builds BinaryContext internally; returns ~22 func_starts on stripped binaries (avoid)
- `sac_for_path(path)` — reads ELF header machine type directly: 0x3=i386 → I386, 0x14=ppc32 → PPC32BE, 0x15 enc=2=ppc64 ELFv1 → PPC64ELFv1, 0x15 enc=1=ppc64 ELFv2 → PPC64ELFv2, 0x16=s390 → S390X, default → SinkArgClassifier

**Architecture dispatch table in `from_context()`:**
- ppc32 → SinkArgClassifierPPC32BE
- x86_32 → SinkArgClassifierI386
- arm32 → SinkArgClassifierARM32
- s390x → SinkArgClassifierS390X
- x86_64 (default) → SinkArgClassifier (self)

**Default sinks (all arg_pos=0):** `system, popen, execve, execvp, execvpe, execl, execlp, execle, execv, __libc_system`

**snprintf-family format arg positions:**
- snprintf → arg_pos 2 (rdx), vsnprintf → 2, `__snprintf_chk` → 4 (r8)
- sprintf → 1 (rsi), vsprintf → 1, `__sprintf_chk` → 3 (rcx), asprintf → 1

**Key methods:**
- `classify_all()` → `List[SinkClassification]`
- `add_sink(name, arg_pos)` — register additional sink
- `batch_plt_intersect(directory, sinks=None, recursive=True)` — scan directory for ELFs whose PLT intersects sink names; exact set membership (never substring); strips versioning suffix before matching; prevents false positives like `check_and_perform_system_login_2factor_auth_unix` matching `system`
- `_extract_plt_x86()` — parses .rela.plt → got_to_sym; scans .plt.sec/.plt/.plt.got stubs for `ff 25` pattern
- `_extract_func_starts()` — uses endbr64 (IBT), push rbp after ret/int3, push r12-r15/rbx/rsi/rdi after ret/int3
- `_count_plt_callers()` — single O(binary_size) pass counting `e8 <rel32>` call targets; pre-filters dead PLT imports
- `_align_func_va()` — searches backward for ENDBR64 or push rbp to correct heuristic func_starts

**SinkClassification namedtuple fields:** `func_va, call_va, sink_name, arg_pos, verdict, detail, severity`

**Lookback window:** 80 instructions (x86-64 default). snprintf window: 140 instructions.

### CAP-A07-03 — SinkArgClassifierI386 (forward register-state pass)

**File:** `sink_arg_classifier_i386.py`  
**Class:** `SinkArgClassifierI386`  
**Gap IDs fixed:** RMC-GAP-002, COMMSVR-GAP-004, HACMP-GAP-001

**Verdict classes:** RODATA_CONST, SNPRINTF_RODATA, ARG_PROPAGATED, UNKNOWN

**Architecture scope:** x86-32 (EM_386 ELF).

**Algorithm:** Single forward disassembly pass builds a `reg_state` dict per function. At each exec PLT call, `reg_state` already holds the current verdict for every register — no lookback limit. Handles register aliases: `mov edi, eax` after `eax=ARG_PROPAGATED` → `edi=ARG_PROPAGATED`. Handles both push-based and sub-esp/mov-[esp+N] calling conventions.

**State transitions:**
- `[ebp+N]` (N>0) → ARG_PROPAGATED
- `[ebp-N]` → local stack slot
- Arithmetic on ARG_PROPAGATED → UNKNOWN
- After any CALL: EAX=UNKNOWN, call_args cleared
- `xor reg, reg` (self-xor) → RODATA_CONST (zero constant)

**Complement to `sink_arg_classifier_x86_32.py`:** Covers long-range register persistence (arg loaded at function entry far from sink call, beyond x86_32 lookback window). x86_32 module has deeper snprintf/strcpy stack-slot backtrack.

**Limits:** Max 2000 instructions per function.  
**Constructors:** `from_context(ctx)`, `from_path(path)`  
**Main method:** `classify_all()` → `List[SinkClassification]`

### CAP-A07-09 — SinkArgClassifierS390X

**File:** `sink_arg_classifier_s390.py`  
**Class:** `SinkArgClassifierS390X` (alias: `SinkArgClassifierS390`)  
**Gap IDs fixed:** S390-GAP-001

**Verdict classes:** RODATA_CONST, SNPRINTF_RODATA, ARG_PROPAGATED, UNKNOWN

**Scope limitation:** Does NOT gate on `callers_of()`. Scans all func_starts.

**Constructors:** `from_context(ctx)`, `from_path(path)`

### CAP-A07-12 — SinkSanitizerFilter

**File:** `sink_sanitizer_filter.py`  
**Class:** `SinkSanitizerFilter`  
**Gap IDs fixed:** TG-FAD-2 (FortiADC authd engagement gap)

**New verdict:** `SANITIZER_VALIDATED` — ARG_PROPAGATED reclassified to LOW severity when all three conditions met.

**Architecture scope:** x86-64 (uses CS_ARCH_X86, CS_MODE_64 internally; depends on SanitizerDetector which is x86-64 only).

**Purpose:** Post-processor for SinkArgClassifier output. Removes manual triage burden for ARG_PROPAGATED sites that pass through a SHELL_SAFE allowlist validator.

**Three reclassification conditions (all must hold):**
1. A SHELL_SAFE sanitizer (detected by SanitizerDetector) is called on the same argument within `_SANITIZER_SCAN_WINDOW` (256) instructions before the exec sink.
2. A conditional branch on the sanitizer's return value guards execution: `test eax, eax / jz <error>` — execution does not reach the exec sink when sanitizer rejects.
3. The argument register at the sanitizer call traces to the same source register as the argument at the exec call (arg-identity check; same variable, not coincidentally shared rdi).

**Engagement context:** FortiADC authd — `auth_sso_krb` (0xd930) was the only ARG_PROPAGATED site without a sanitizer guard. Five other ARG_PROPAGATED sites would have been auto-downgraded.

**Key scanning constants:**
- `_SANITIZER_SCAN_WINDOW` = 256 instructions back from exec call
- `_GUARD_SCAN_WINDOW` = 12 instructions after sanitizer call for test+branch guard
- `_TRACE_LOOKBACK` = 80 instructions for arg source tracing

**`_trace_first_arg_source(insns, call_idx)`:**
- Traces rdi backward; returns canonical register name, 'STACK', or None
- Follows one level through non-volatile registers (r12–r15, rbx, rbp)
- Does NOT follow caller-saved registers across CALL instructions
- Returns 'STACK' when rdi set via lea [rsp/rbp+N]

**Constructors:** `from_path(path)`, `from_context(ctx)`  
**Main method:** `apply(classifications)` → `List[SinkClassification]` (returns new list), `report(classifications)` → str

### CAP-A07-13 — SanitizerDetector

**File:** `sanitizer_detector.py`  
**Classes:** `SanitizerDetector`, `SanitizerProfile`, `SanitizerCoverageReport`  
**Gap IDs fixed:** None listed (enables downstream gap closure via SinkSanitizerFilter)

**Architecture scope:** Detection (SanitizerDetector): x86-64 only. Coverage audit (`audit_coverage()`): arch-agnostic (text-based parsing; supports PPC64, x86, ARM64, MIPS).

**Purpose:** Identify allowlist byte-validator functions in x86-64 ELF binaries.

**Detection signature (5 criteria):**
1. Function length < 128 instructions
2. Byte-load loop: `movzx eX, byte ptr [...]` in a backward-edge loop
3. Range/equality comparisons: `cmp` + `ja/jb/je/jne` against specific immediates
4. Dual return values: one path returns 0, another returns 1
5. No calls to printf-family, malloc, or other heavy functions

**Scoring weights:** W_BYTE_LOAD=3, W_RANGE_CMP=2, W_DUAL_RETURN=2, W_NO_CALLS=2, W_BACKWARD_EDGE=1. Minimum qualifying score = 4.

**RC score:** Concentration of ASCII comparisons on same register that received byte loads (guards against math/crypto false positives).

**Shell metacharacters detected (20 chars):** `;`, `|`, `&`, `$`, `` ` ``, `'`, `"`, `(`, `)`, `<`, `>`, `!`, `\`, newline, space, tab, `*`, `?`, `[`, `~` — byte range 0x09–0x7e only.

**Known limitation:** Tab (0x09) and newline (0x0a) not detectable via inline-compare pattern (excluded from IMM range 0x20–0x7e).

**SanitizerProfile verdicts:** SHELL_SAFE, SHELL_UNSAFE, PARTIAL, UNKNOWN  
**`shell_safe` property:** True when verdict == SHELL_SAFE.

**SanitizerCoverageReport verdicts (arch-agnostic `audit_coverage()`):**
- `SHELL_SAFE` — all 20 shell metacharacters covered
- `PARTIAL` — some covered
- `SPACE_ONLY` — only space (0x20) checked
- `NO_CHECKS` — no byte comparisons found
- `UNKNOWN` — analysis failed

**Constructors:** `SanitizerDetector.from_path(path)`, `from_context(ctx)`  
**Main methods:** `detect()` → `List[SanitizerProfile]`, `audit_coverage(func_va)` → `SanitizerCoverageReport`

### CAP-A07-14 — StaticLinkSinkScanner

**File:** `static_link_sink_scanner.py`  
**Class:** `StaticLinkSinkScanner`  
**Gap IDs fixed:** SAC-STATIC-001 (system()), SAC-STATIC-002 (popen()), SAC-STATIC-003 (strcpy/strcat)

**Purpose:** Locate exec-class sinks in statically linked ELFs where SAC returns 0 because there is no PLT. Targets: BTT52iFix, VE/UninstallAssistantLinux, HMC-V11/img2a, IBM POWER tools.

**Strategy:**
- system()/popen(): Locate `/bin/sh\x00` in .rodata; find every function that xrefs it with LEA/MOV; the function also containing an execve() call or waitpid loop is `system()`. All call sites to that function are `system()` call sites.
- strcpy()/strcat(): Heuristic — scan for functions whose first argument is rdi and which call memcpy or rep movsb. Marked UNKNOWN-STATIC.

**StaticSinkResult dataclass fields:** `call_va, sink_name, sink_impl_va, verdict, arg_evidence, byte_verified`

**Verdicts:** RODATA_CONST, ARG_PROPAGATED, UNKNOWN-STATIC

**Architecture support:**
- x86-64: full — system via /bin/sh xref + CALL rel32 scan + rdi classification
- x86-32: full — system via /bin/sh xref + CALL rel32 i386 + last-push classification
- PPC64/PPC32: /bin/sh xref locates system_impl VA; call scan uses BL/BLA instruction encoding (opcode=18, relative, link bit set); arg classification falls back to UNKNOWN-STATIC
- Others: /bin/sh xref only; call scan falls back to UNKNOWN-STATIC

**BL encoding (PPC):** `0x48000001 | (offset & 0x03FFFFFC)` where offset = signed, word-aligned.

**xref scanning:**
- x86-64: scans for `REX.W 8D <ModRM=0x?5> rel32` (RIP-relative LEA, any GPR dest)
- x86-32: scans for `0x68 <imm32>` (PUSH imm32)
- PPC: falls back to proximity in func_starts (addis/addi pair too complex for first pass)

**Byte verification:** `_byte_verify(call_va, target_va)` — verifies CALL bytes; sets `byte_verified=True` on result.

**`find_system_impl()`** — returns VA of statically-linked system(), or None.

**Constructors:** `from_context(ctx)`, `from_path(path)`  
**Main methods:** `scan_system()` → `List[StaticSinkResult]`, `scan_exec_sinks()` → sorted `List[StaticSinkResult]`, `report(results)` → str

### CAP-A07-15 — NetworkSinkFinder

**File:** `network_sink_finder.py`  
**Class:** `NetworkSinkFinder`  
**Gap IDs fixed:** HACMP-003

**Purpose:** Automates the HACMP-003 pattern — find network-reachable ARG_PROPAGATED/UNKNOWN exec sinks without manual reachability analysis.

**Default network sources:** `recv`, `recvfrom`, `recvmsg`, `read`, `fgets`, `gets`, `fread`, `accept`, `accept4`.

**Algorithm:**
1. Find network source PLT VAs (matched by containment to handle `@@GLIBC_2.x` suffixes)
2. Find callers of each network source; seed BFS
3. BFS reachability from seed callers up to `depth` (default 3); track minimum depth per VA
4. Run SinkArgClassifier via `SinkArgClassifier.from_context(ctx)` (arch-aware dispatch)
5. Cross-reference: keep only results whose function is in reachable set

**Deduplication priority per function:** ARG_PROPAGATED(3) > UNKNOWN(2) > SNPRINTF_RODATA(1) > RODATA_CONST(filtered entirely).

**NetworkSinkResult fields:** `func_va, func_name, sink_name, verdict, depth, source_syms`

**Constructor:** `NetworkSinkFinder.from_context(ctx, depth=3, net_source_names=None, extra_sinks=None)`

**Main methods:** `find(depth=None)` → `Dict[int, NetworkSinkResult]`, `report(findings=None)` → str

### CAP-A07-17 — ArgvBuildToSinkClassifier

**File:** `argv_build_to_sink.py`  
**Class:** `ArgvBuildToSinkClassifier`  
**Gap IDs fixed:** HMCMGMT-CMD-001 (ldapsearch SETUID hscroot pattern)

**Purpose:** Detect malloc→strcat(argv[i] loop)→system/popen injection pattern where SAC returns UNKNOWN because the strcat source is dynamic.

**Architecture scope:** x86 and x86_64 only. Returns `[]` for other architectures.

**Pattern detected (in a single function):**
1. `call malloc/calloc/alloca` — allocate command buffer
2. (optional) `strcpy/strncpy` initial template into buffer
3. Loop: `call strcat(buf, argv[i])` where i is a loop counter
4. `call system(buf)` / `popen(buf)` / `execvp(buf)` — exec sink

**ArgvBuildFinding dataclass fields:** `func_va, alloc_va, strcat_vas, sink_va, sink_name, gate_funcs, gate_strings, no_gate, verdict, severity, note`

**Gate scoring:**
- No gate detected → severity = HIGH
- `getuid`/`geteuid` present → severity = MEDIUM
- `strcmp` to `'root'`, `'hmcroot'`, `'hscroot'` → severity = LOW
- Other `strcmp`/`getpwnam` → severity = MEDIUM

**Verdict rules:**
- `CONFIRMED` — (alloc_va OR strcat_vas present) AND no_gate=True
- `PLAUSIBLE` — gate present or weaker evidence

**argv detection:** `_second_arg_from_argv()` — checks if second arg to strcat is `[rbp+rax*8+N]` or `[rbp+N+rax*8]` pattern or indirect `[rax]` loaded from argv.

**Constructors:** `from_path(path)`, `from_context(ctx)`  
**Main method:** `scan()` → `List[ArgvBuildFinding]`
