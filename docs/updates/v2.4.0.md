# v2.4.0 (2026-09-24): Format string scanner, MIPS32 taint, BYOVD detector, heap scanner, IOCTL surface, cross-binary taint

Six new analyzers ship in this release.

- **Format string scanner** (`ablation fmtstr`): scans x86-64 ELF for printf/syslog/err family calls where the format argument is not a string literal; backward trace from each call site classifies the format register as SAFE (LEA into .rodata), VULNERABLE (stack slot or entry arg), or SUSPICIOUS (global var, computed value); 28 sinks including glibc fortify variants; two-hop detection catches the TAOSSA ch.8 pattern where a `vsnprintf` output buffer is reused as the format argument to `syslog`
- **MIPS32 taint tracker** (`ablation mips`): source-to-sink taint analysis for MIPS32 ELF binaries; O32 ABI register model; load-delay slot aware; big-endian (RouterOS, Broadcom) and little-endian (embedded CPE) support; sources: recv/recvfrom/read/fgets/gets/fread; sinks: system/execve/execl/popen/strcpy/sprintf/memcpy/strcat/snprintf; intraprocedural and interprocedural BFS up to depth 4
- **BYOVD detector** (`ablation byovd`): scores Windows kernel drivers 0-100 across 8 Bring Your Own Vulnerable Driver attack paths: `MmMapIoSpace` with user-controlled physical address, MDL-based kernel write, MSR_LSTAR manipulation, SSDT hook via CR0 WP-disable, token stealing via PsInitialSystemProcess, SMEP bypass via CR4, APC kernel injection, ZwWriteVirtualMemory; signed driver + METHOD_NEITHER IOCTL + dangerous primitive = BYOVD_CONFIRMED
- **Heap vulnerability scanner** (`ablation heap`): four classes grounded in TAOSSA ch.5 and ch.6: INT_OVERFLOW_BEFORE_ALLOC (IMUL/MUL/SHL result to malloc without overflow check), USE_AFTER_FREE (freed pointer dereferenced in same function), DOUBLE_FREE (same register freed twice), OFF_BY_ONE_ALLOC (strlen without +1 for NUL terminator)
- **IOCTL attack surface** (`ioctl_attack_surface.py`): generates a per-IOCTL handler attack surface report for Windows kernel drivers; pairs each decoded CTL_CODE with the handler's disassembly window; flags METHOD_NEITHER codes; annotates dangerous APIs reached within the handler
- **Cross-binary taint** (`cross_binary_taint.py`): follows taint across shared library boundaries via LibGraph; seeds tainted return values at each export crossing; BFS-tracks them through callee chains; produces source-to-sink paths that span multiple `.so` files in a firmware image

## Usage

```bash
ablation fmtstr  binary.elf
ablation mips    firmware.elf [--le]
ablation byovd   driver.sys
ablation heap    binary.elf
```

```python
from ablation.analyzers.format_string_scanner import FormatStringScanner
from ablation.analyzers.taint_tracker_mips import MIPS32TaintTracker
from ablation.analyzers.byovd_detector import BYOVDDetector
from ablation.analyzers.heap_vuln_scanner import HeapVulnScanner
from ablation.analyzers.ioctl_attack_surface import IoctlAttackSurface
from ablation.analyzers.cross_binary_taint import CrossBinaryTaintTracker

# Format string
scanner = FormatStringScanner.from_context(ctx)
findings = scanner.scan()
print(scanner.report([f for f in findings if f.verdict != 'SAFE']))

# MIPS32 taint (big-endian RouterOS)
tracker = MIPS32TaintTracker.from_path('router.elf', endian='big')
chains = tracker.run_interprocedural(depth=4)

# BYOVD
result = BYOVDDetector.from_path('driver.sys').analyze()
print(result.fmt())   # score, verdict, attack paths found

# Heap
findings = HeapVulnScanner.from_context(ctx).scan()

# Cross-binary
tracker = CrossBinaryTaintTracker.from_lib_graph(lg)
paths = tracker.run()
```
