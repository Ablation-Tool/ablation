## Why this exists <sup>[↑](#hdlhtmlextractor)</sup>

1. **HDL Designer exports VHDL/Verilog as HTML, not as source files.** The ATLAS ITk strip detector design environment used Mentor HDL Designer for schematic-driven VHDL entry. Exports produced frameset HTML files rather than raw `.vhd` files. `VerilogSemantic.from_directory()` only reads `.v`/`.vhd`/`.vhdl` — it cannot process `.htm` exports directly.

2. **The HTML format is uniform but not self-evident.** Each source file produces a frameset `.htm` + `ContentFrame0.htm` (source code) + `ContentFrame1.htm` (diagram canvas, always empty) + `ToolbarFrame*.htm` (navigation). Only `ContentFrame0.htm` contains source code, wrapped in a `<pre>` block with `<span class=K/C/T/S>` syntax coloring. Knowing which file to read and which tags to strip is the whole problem.

3. **The affected collection spans six hardware blocks.** LCB downlink (10 source files), STAR FLINK readout (5), Atlys ITSDAQ (17), HSIO (29), OCB (10), readout130 (7) — all stored as HDL Designer HTML exports at `/media/cowboy/research/CERN/docs/htmlexport/`. Extracting these by hand for each RE pass was the pattern before this module existed.

---

## How it works <sup>[↑](#hdlhtmlextractor)</sup>

`from_directory()` scans recursively for `*ContentFrame0.htm` files. For each:

1. Validates the `<!-- Generated by HDL Designer -->` comment — rejects non-HDL-Designer HTML.
2. Extracts the `<pre>...</pre>` block.
3. Strips all `<tag>` markup and decodes HTML entities (`&amp;`, `&lt;`, `&gt;`, `&nbsp;`, `&quot;`, `&#39;`).
4. Checks for the `"Side Data was not exported"` sentinel — skips diagram-only frames.
5. Maps the stem name to a canonical source filename: `lcb_decoder_vhd` → `lcb_decoder.vhd`.

`ContentFrame1.htm` is always a diagram canvas. It always says `"Side Data was not exported"` in the known ATLAS collection. The extractor handles it correctly but never produces an entry from it.

`to_semantic()` calls `_extract_vhdl()` / `_extract_verilog()` on the clean text in-memory, returning a `VerilogSemantic` with `src_dir` set to the original HTML directory. No disk writes required.

## HdlHtmlExtractor <sup>[↑](#hdlhtmlextractor)</sup>

```python
from ablation.analyzers.hdl_html_extractor import HdlHtmlExtractor

ext = HdlHtmlExtractor.from_directory(htm_dir)
```

**Key methods:**

| Method | Returns | Notes |
|---|---|---|
| `from_directory(path)` | `HdlHtmlExtractor` | Recursive scan; follows subdirs |
| `source_files()` | `List[str]` | Sorted canonical source filenames |
| `text(source_name)` | `str` | Clean VHDL/Verilog text |
| `texts()` | `Dict[str, str]` | All source texts |
| `to_semantic()` | `VerilogSemantic` | In-memory — use for constants/query |
| `write_vhd(output_dir)` | `List[str]` | Disk output for HDLVersionDiff |
| `report()` | `str` | Summary: file count + line counts |
| `len(ext)` | `int` | Number of source files found |

## Usage <sup>[↑](#hdlhtmlextractor)</sup>

**Extract constants from an HDL Designer export:**

```python
from ablation.analyzers.hdl_html_extractor import HdlHtmlExtractor

ext = HdlHtmlExtractor.from_directory(
    '/media/cowboy/research/CERN/sims/lcb/downlink/'
)
vs = ext.to_semantic()
print(vs.constants())        # MAP_6B_8B, MAP_K_8B, WORDWIDTH, ...
print(vs.modules())          # lcb_decoder, lcb_frame_sync, ...
```

**Feed into HDLVersionDiff (two HTML export versions):**

```python
import tempfile
from ablation.analyzers.hdl_html_extractor import HdlHtmlExtractor
from ablation.analyzers.hdl_version_diff import HDLVersionDiff

with tempfile.TemporaryDirectory() as v1_dir, \
     tempfile.TemporaryDirectory() as v2_dir:
    HdlHtmlExtractor.from_directory(htm_v1).write_vhd(v1_dir)
    HdlHtmlExtractor.from_directory(htm_v2).write_vhd(v2_dir)
    diff = HDLVersionDiff.from_directories(v1_dir, v2_dir, "v1", "v2")
    print(diff.report())
```

**Read a specific file's clean text:**

```python
ext = HdlHtmlExtractor.from_directory('/media/cowboy/research/CERN/sims/star_flink/readout130/')
print(ext.text('pkg_star_flink.vhd'))
```
