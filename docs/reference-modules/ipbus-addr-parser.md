# IPBusAddrParser

**Module**: `ablation/analyzers/ipbus_addr_parser.py`
**Gap**: IPBUS-ADDR-TABLE-GAP-001

---

## Why this exists

1. IPBus firmware (facility ATLAS GEP, EMP framework, TriDAS FELIX) ships register maps as XML address tables. Without parsing these, register addresses captured from live IPBus TCP traffic are opaque 32-bit word offsets.
2. The facility GEP rootfs contains `addr_table_a.vhd`, `addr_table_b.vhd` (auto-generated VHDL from XML). Parsing the source XML files directly recovers the full register map including symbolic names, permissions, and bitmask fields.
3. IPBus protocol is unauthenticated on the GEP (ports 8061–8064). Mapping which addresses are writable from the network is the primary threat model.

---

## IPBus XML address model

```xml
<node id="module_root" address="0x0">
  <node id="csr" address="0x2" permission="rw" description="Control/status">
    <node id="enable" mask="0x0001"/>
    <node id="reset"  mask="0x0002"/>
  </node>
  <node id="id" address="0x0" permission="r" description="Firmware ID"/>
</node>
```

- Addresses are **32-bit word addresses** (byte_addr = word_addr × 4)
- Child addresses are relative to parent absolute address
- `permission`: `r` = read-only, `w` = write-only, `rw` = read-write (default)
- `mask`: bit field within a register (child of a register node)

## Constructor patterns

```python
from ablation.analyzers.ipbus_addr_parser import IPBusAddrParser

# From an XML file extracted from firmware
parser = IPBusAddrParser.from_file('/tmp/addr_table_a.xml')
reg_map = parser.parse()

# From a string (e.g., extracted from icat)
parser = IPBusAddrParser.from_string(xml_text, label='gep_addr_table')
reg_map = parser.parse()

# Print full register map
print(parser.report(reg_map))

# Lookup by word address (e.g., from IPBus TCP capture)
node = reg_map.lookup_addr(0x4)
if node:
    print(node.full_path, node.permission, node.description)

# All writable registers (attack surface)
for node in reg_map.writable():
    print(f'0x{node.byte_addr:08x}  {node.full_path}  [{node.permission}]')

# All readable registers
for node in reg_map.readable():
    print(node.full_path, f'0x{node.abs_addr:x}')

# Walk entire tree depth-first
for node in reg_map.walk():
    if node.is_leaf:
        print(node.path, node.abs_addr)
```

## IPBusRegisterMap fields

```python
reg_map.source     # source XML path/label
reg_map.nodes      # List[IPBusNode] — top-level nodes
reg_map.flat       # Dict[abs_word_addr, IPBusNode] — deepest node at each address
reg_map.path_map   # Dict[dotted_path, IPBusNode]
reg_map.writable() # List[IPBusNode] sorted by address
reg_map.readable() # List[IPBusNode] sorted by address
```

---

## IPBusNode fields

```python
node.id          # e.g. 'csr'
node.abs_addr    # absolute word address
node.byte_addr   # abs_addr × 4
node.permission  # 'r', 'w', 'rw', or ''
node.mask        # int or None (bit field mask)
node.description # from XML description attribute
node.path        # dotted path, e.g. 'module.csr.enable'
node.children    # List[IPBusNode]
node.is_leaf     # True if no children
node.is_writable # True if 'w' in permission
```

## Finding IPBus XML files in firmware

IPBus address tables are typically embedded in:
- Python packages: `ipbus_xml/` directories in DAQ software tarballs
- C++ headers: auto-generated by `gen_ipbus_addr_decode` from the XML
- VHDL: `ipbus_decode_addr_table_*.vhd` (auto-generated; does NOT contain register names)

To recover the original XML from a VHDL decode file, use `gen_ipbus_addr_decode` in reverse (not supported here) or look for the source XML in firmware tarballs/GitLab repos.

---

## Known limitations

- Macro references (`$(ADDRTABLE.X)`) in address attributes are treated as offset 0 — they require resolving the referenced XML file.
- Does not validate the XML schema against the uHAL DTD.
- `flat` map uses last-writer-wins for nodes sharing an address (e.g., a container and its first child at the same offset).
