# AIControlIndicators

## Why this exists

Three gaps motivated this module:

1. Binaries containing AI-generated code show elevated vulnerability rates compared to human-written code. Flagging these binaries early prioritizes reviewer effort.
2. AI code generation tools often embed attribution strings, hallucinated package names, and comment templates that survive compilation into string tables.
3. No existing Ablation scanner checked for AI generation markers before full semantic analysis.

## What it does

`AIControlIndicators` scans binary string tables for three classes of AI code marker:

- **Attribution strings**: direct tool credit strings such as "Generated by GitHub Copilot" or "Generated by ChatGPT"
- **Hallucinated package names**: import stub strings for packages that do not exist in public registries
- **Comment patterns**: characteristic AI-generated comment templates compiled into string tables

All findings are severity MEDIUM. They serve as triage signals, not direct vulnerabilities.

## Constructor

```python
from modules.ai_control_indicators import AIControlIndicators

# From path
detector = AIControlIndicators('/path/to/binary')

# From BinaryContext
detector = AIControlIndicators.from_context(ctx)
```

## Methods

| Method | Returns | Notes |
| ------ | ------- | ----- |
| `scan()` | `list[AICodeFinding]` | Full scan across all 3 indicator classes |
| `report(findings=None)` | `str` | Formatted text report |

## AICodeFinding dataclass

```python
@dataclass
class AICodeFinding:
    indicator_type: str   # 'attribution_string', 'hallucinated_package', 'comment_pattern'
    matched:        str   # the matched string
    severity:       str   # always 'MEDIUM'
```

## Coverage

**Attribution strings checked:** GitHub Copilot, ChatGPT, GPT-4, Claude, Amazon CodeWhisperer, Tabnine, Codeium, and generic "AI-generated code" markers.

**Hallucinated package names checked:** langchain-tools, openai-functions, anthropic-sdk-extra, gpt-utils, copilot-helper, chatgpt-client, ai-helper-utils, openai-helper, langchain-community-extra.

**Comment patterns checked:** "This function takes/accepts/returns/handles/checks/validates", boilerplate TODO templates, and Javadoc-style auto-generated blocks.

## Severity and triage

A single MEDIUM finding indicates AI code is present and warrants elevated review priority. It does not indicate a specific vulnerability. Follow with `WeakPRNGAtSecuritySinkScanner`, `TruncationAtSinkScanner`, and `HardcodedCredentialScanner` runs, which are the vulnerability classes most over-represented in AI-generated code.
