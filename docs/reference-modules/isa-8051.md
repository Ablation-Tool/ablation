# Intel MCS-51 / CC254x Decoding

`modules.isa_8051` is an implemented pure-Python MCS-51 decoder and Intel HEX loader, with CC254x bank-address helpers and AES/bank-switch classification. It supports enhanced 8051 firmware analysis without Capstone. It does not provide pseudo-C decompilation or the previously proposed `Mcs51TaintTracker`.

## Why this is more than an opcode table

MCS-51 firmware combines record-oriented input, several distinct memory spaces, and sometimes banked code. Correct instruction bytes alone do not resolve which bank is active or whether two equal numeric addresses refer to the same storage. Users need format, address, and instruction handling to remain separate but composable.

The shared HEX parser validates stored addresses, the decoder classifies operations, and the CC254x helper translates candidate bank mappings. This provides a dependable starting point for locating calls, bank switches, and AES-register accesses without claiming emulation or decompilation. Each piece can evolve independently, including replacement of the compatibility loader by the shared parser. Security conclusions still require the target's bank-selection and peripheral behavior.

## Decode a flat image

```python
from modules.isa_8051 import Mcs51Decoder

decoder = Mcs51Decoder()
instructions = decoder.decode_range(data, start=0, end=min(len(data), 0x400))
for insn in instructions:
    print(insn)
```

`decode_one(data, offset)` returns one `Mcs51Insn`; `decode_range()` returns a list for the selected half-open byte range. Each instruction exposes flat `offset`, `raw`, `mnemonic`, `operands`, `insn_type`, optional `target`, and derived `size`.

Control-flow types distinguish calls, jumps, conditional branches, returns, computed jumps, and TI's computed-call stub idiom. Pass `computed_call_stub=` to `Mcs51Decoder` when the target uses that inline-data convention so the stub's following data bytes are not decoded as instructions.

Properties such as `is_call`, `is_branch`, `reads_aes_sfr`, `writes_aes_sfr`, and `changes_bank` support targeted review. `scan_aes_accesses()` and `scan_bank_switches()` apply those classifications across an instruction iterable.

## Load Intel HEX

```python
from modules.isa_8051 import IntelHexLoader

loader = IntelHexLoader.from_file('/path/to/cc2541.hex')
base_address, end_address = loader.address_range()
data = loader.to_bytes()
```

`IntelHexLoader` is a compatibility wrapper around [the shared strict Intel HEX parser](intel-hex.md). It validates checksums, lengths, EOF, trailing content, and conflicting overlaps while preserving the existing `from_file()`, `from_bytes()`, `address_range()`, `to_sparse()`, and `to_bytes()` API. All standard address and start-address record types are supported. Input text is limited to 4 MB and dense address ranges to 512 KB. `to_bytes(fill=0xFF)` fills gaps by default and honors other fill values.

## Resolve CC254x banks

```python
from modules.isa_8051 import Cc254xBankResolver

resolver = Cc254xBankResolver(num_banks=4)
bank, logical_address = resolver.flat_to_logical(flat_offset)
flat_offset = resolver.logical_to_flat(bank, logical_address)
```

The resolver maps flat image offsets to bank/logical-code-address pairs and identifies candidate cross-bank calls. Runtime bank selection still matters: a logical address in the banked window is not enough to prove which bank is active at a call site.

## Limitations

- Offsets from the decoder are flat buffer offsets, not automatically runtime code addresses. Use the bank resolver for CC254x images.
- MCS-51 has separate CODE, IRAM, XDATA, SFR, and bit-addressable spaces. Equal numeric addresses in different spaces are not aliases.
- SFR and AES properties classify encoded accesses; they do not emulate the AES peripheral or track values through memory.
- The module decodes and classifies instructions. It does not build a full CFG, infer C types, or implement the unimplemented taint-tracker proposal from older documentation.
- Validate computed-call and banking conventions against the specific TI firmware before trusting call targets.
