# Cognitive Field visual provenance

The three images in this directory are **user-supplied visual references**, not generated Zoe output and not executable models:

- `reference-temporal-layers.png` — supplied as `Untitled drawing.jpg`; the retained PNG was rendered from the equivalent supplied PDF. Root/temporal structure, object-tree tables, and colored layered blocks.
- `reference-hub-lattice.png` — supplied as `Untitled drawing (1).png`; an equivalent supplied PDF export was inspected. A spatial hub/lattice composition.
- `reference-memory-flow.png` — supplied as `Untitled drawing.png`; an equivalent supplied PDF export was inspected. Memory boundaries, projection imagery, raster planes, and layered blocks.

The earlier supplied `Screenshot From 2026-11-05 01-54-16.png` informed the distinction between a physical viewport and the logical work area. The supplied memory-architecture screenshot informed the overall information flow. These sources remain references; Zoe does not execute them or treat their labels as scientific validation.

`guiai-lab/docs/images/zoe-cognitive-field.{png,svg,gem}` is original executable Spatial IR generated by `guiai.gem.cognitive.cognitive_scene`. It uses the **Z.O.E. · Cognitive Field / GSP** identity, simple layered polygons for active memory, a compact context legend, and a text-preserving event chain. **GSP** means General Symbol Processor: explicit text, tags, IDs, revisions, and rule descriptions, not the historical General Problem Solver or a claim of general intelligence. It does not reproduce the supplied compositions or their embedded book/medical figures. No CNN, anatomical registration, or clinical reconstruction is implemented by this module.

`guiai-lab/docs/images/zoe-cognitive-native.png` is a screenshot of the actual GTK module running the deterministic worked example under nested X11.

The later anatomical/cognitive-pipeline figure is a user-supplied visual reference associated with the supplied [Cognitive architecture Wikiquote page](https://en.wikiquote.org/wiki/Cognitive_architecture), whose caption identifies the architecture as **Spaun**. It is not a Zoe architecture diagram. Zoe does not implement Spaun, cortical localization, reward estimation, action selection, or motor output. Encoding, transforms, decoding, and review are kept distinct from biological claims.

`zoe-cognitive-anatomy.{png,svg}` is an original composite generated by `assets/cognitive-dialogue/render.py`. It reuses Zoe's existing organic brain illustration and new GSP diagrams; it does not copy the supplied Spaun figure. The paired panels are explicitly a reference, not an equivalence. The left side is artistic anatomy, not a medical image or brain scan. The right side depicts actual software boundaries, with motor output replaced by review-required proposals.

The original accessible-volume equation used in the measurement chamber is credited to **Nicholas Michael Kloster alone, March 6, 2026**. Zoe's Cognitive Field is not ACT-R, Spaun, a consciousness model, or an autonomous action system.
