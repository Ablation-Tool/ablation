# v2.5.0 (2026-09-24): FormatStringScanner fortify variants, IoctlAttackSurface, CrossBinaryTaint, BYOVDDetector PDB fingerprints

Refinements and additions across the Windows and cross-binary analysis layers.

- **FormatStringScanner** (`ablation fmtstr`): TAOSSA ch.8 grounded; 28 printf/syslog/err sinks; backward trace per call site classifies format arg as SAFE (LEA .rodata), VULNERABLE (arg register, stack slot, recv return), or SUSPICIOUS; glibc fortify variants (`__printf_chk`, `__fprintf_chk`, `__snprintf_chk`) covered
- **IoctlAttackSurfaceGenerator** (`ablation ioctl-surface`): per-IOCTL attack surface report for Windows kernel drivers; METHOD_NEITHER without ProbeForRead = CRITICAL; allocation before InputBufferLength validation = HIGH; TYPE3_INPUT_BUFFER direct dereference = HIGH; Markdown report via `report_markdown()`
- **CrossBinaryTaintTracker**: LibGraph-backed cross-library BFS; follows tainted arguments through PLT entries into exporting shared libraries; resolves PLT symbol to exporting binary via `LibGraph.defined_in()`; returns `TaintChain` with full cross-binary hop provenance
- **BYOVDDetector** (`ablation byovd`): expanded to 12 capability classes including PHYS_MEM_RW, TOKEN_STEAL, DKOM, APC_INJECT, DRIVER_LOAD, CALLBACK_REMOVE, PROCESS_KILL, MSR_WRITE; known-driver PDB fingerprint table covers mhyprot, RTCore64, dbutil, PROCEXP, iqvw64e, cpuz

## Usage

```bash
ablation fmtstr        binary.elf [--json findings.json]
ablation ioctl-surface driver.sys [--json report.json]
ablation byovd         driver.sys
```

```python
from ablation.analyzers.ioctl_attack_surface import IoctlAttackSurfaceGenerator
from ablation.analyzers.cross_binary_taint import CrossBinaryTaintTracker
from ablation.analyzers.byovd_detector import BYOVDDetector

# Per-IOCTL surface report
gen = IoctlAttackSurfaceGenerator.from_path('driver.sys')
print(gen.report_markdown())

# Cross-binary taint (requires LibGraph)
tracker = CrossBinaryTaintTracker.from_lib_graph(lg)
paths = tracker.run()

# BYOVD with PDB fingerprint matching
result = BYOVDDetector.from_path('driver.sys').analyze()
print(result.fmt())   # score, verdict, known-driver match if any
```
