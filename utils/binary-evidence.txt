RFC COMPLIANCE:
  RFC 5080 §2.2 requires: if Access-Request includes Message-Authenticator,
  the Access-Accept MUST include Message-Authenticator.
  RFC 2865 does not mandate Message-Authenticator on Access-Accept.
  Cisco ASA does not require or validate Message-Authenticator on
  Access-Accept in any known version. The attack exploits this gap.

RELATED CVE:
  CVE-2024-3596 (BlastRADIUS) — DOES NOT COVER F1/F2.
  BlastRADIUS targets Access-Request MD5 chosen-prefix collision injection,
  a different attack vector. F1/F2 exploit the Access-Accept response path
  using only the known RADIUS shared secret.

FINDING F2: RADIUS Class Attribute Pointer Corruption (CRITICAL)
=============================================================

SEVERITY: CRITICAL
Cisco AI (11:06): "A 96-byte OU= value will overflow the 32-byte
group_policy_name and overwrite the wins-server/dns-server pointer
fields in the group policy object. This allows an attacker to control
pointers that the ASA will later dereference, creating a high risk of
memory corruption and potential code execution. This is a critical
security issue."

ROOT CAUSE:
  The OU= extraction loop (0x03a4bfa4: CMP rax,0x100) allows up to
  256 bytes. This value is written via strncpy (0x01a30894) into
  gp_obj+0x2b1, a 32-byte char array within the heap-allocated group
  policy object. session+0x0c is a POINTER to this gp_obj. The
  strncpy bound ([r15+0x08] from attr_def table 0x76f20a0) is not
  statically constrained to the 32-byte array size.

  A OU= value of 96+ bytes overflows the 32-byte name array and
  reaches pointer fields the ASA dereferences during VPN session setup.

CONFIRMED GP_OBJ FIELD LAYOUT (9.22.2.32, from apply fn 0x1046d00):

  gp_obj + 0x2b1 : group_policy_name  [char[32]] <- OVERFLOW ORIGIN
  gp_obj + 0x2d1 : default-domain / split-dns    [char[257]]
  gp_obj + 0x308 : wins-server (primary)  [PTR, 8 bytes] <- +96 bytes
  gp_obj + 0x310 : wins-server (secondary)[PTR, 8 bytes]
  gp_obj + 0x318 : dns-server (primary)   [PTR, 8 bytes]
  gp_obj + 0x320 : dns-server (secondary) [PTR, 8 bytes]
  gp_obj + 0x3d2 : gateway-fqdn / msie-proxy-server [char[~129]]
  gp_obj + 0x434 : split-tunnel-policy    [DWORD enum]
  gp_obj + 0x453 : dhcp-network-scope     [char[~64]]

  session + 0x000c : POINTER to gp_obj (not inlined array)
  session + 0x1a78 : session_type (DWORD)
  session + 0x31a8 : vpn_state_machine (DWORD; written by 0x3256dd0)

OVERFLOW THRESHOLDS:
  +33 bytes: gp_obj+0x2d1 overwritten (default-domain/split-dns)
  +96 bytes: gp_obj+0x308 overwritten (wins-server primary POINTER)
  +104 bytes: gp_obj+0x310/+0x318 overwritten (additional server PTRs)
  +128 bytes: all four server pointer fields corrupted
  +256 bytes: maximum OU= extraction, full gp_obj corruption

EXPLOITATION PATH:
  1. Same prerequisites as F1 (RADIUS shared secret + network position)
  2. Inject OU=<96-byte payload>; in Access-Accept Class attribute
     (no Message-Authenticator required — F1 prerequisite enables F2)
  3. strncpy copies 96 bytes into 32-byte array at gp_obj+0x2b1
  4. gp_obj+0x308 overwritten with attacker-controlled bytes
  5. ASA dereferences gp_obj+0x308 during VPN session policy apply
  6. Arbitrary memory read / write / code execution in LINA process

  LINA runs as root on ASA hardware. Code execution = full device
  compromise: config exfiltration, persistent backdoor, traffic
  interception, or use as pivot into protected network segments.

KEY BINARY ADDRESSES (9.22.2.32):
  0x03a4bfa4 : extraction loop bound (CMP rax, 0x100 = 256)
  0x01a30894 : strncpy(gp_obj+0x2b1, attr_val, [r15+0x08])
  0x01046d00 : gp_obj apply function (accesses +0x308 ptr fields)
  0x76f20a0  : attr_def table (runtime; max_length at entry+0x08)

  mgd_timer + 0x2b : flags byte (bit 0x02 = list-walk trigger)

EXPLOITATION PRIMITIVE:
  Craft a fake mgd_timer struct at attacker-controlled heap address A:
    A+0x18 = 0 (terminate list walk)
    A+0x20 = target_argument (passed as RDI to 0x102a520)
    A+0x2a = 0x42 ('B')
    A+0x2b = 0x00 (no list walk)

  Overflow gp_obj+0x2b1 with 96 bytes ending in ptr_to_A at offset +0x308.
  On next VPN session teardown: mgd_timer_stop(A) executes, survives type
  check, calls 0x102a520(A+0x20) with attacker-controlled argument.

  LINA runs as root. 0x102a520 = inner timer dispatch function.
  Result: arbitrary argument to inner timer code in root context.
